# Portfolio Identity Kit: Decide Once

## 1. Typography

- **Heading Font:** `Inter` (Sans-Serif, Semi-Bold / 600)
- **Body Font:** `Inter` (Sans-Serif, Regular / 400)
- **Type Scale & Pairing Rationale:** A single versatile variable font (`Inter`) keeps loading speeds instant, maintains crisp legibility on high-DPI displays, and provides a modern, functional developer aesthetic.

---

## 2. Color Palette

| Usage              | Color Name      | Hex Code  | Purpose                                                                                                |
| :----------------- | :-------------- | :-------- | :----------------------------------------------------------------------------------------------------- |
| **Background**     | Canvas Light    | `#F8F9FA` | Near-white, neutral background reducing eye strain compared to pure white.                             |
| **Text & Content** | Charcoal Ink    | `#111827` | High-contrast, near-black primary text for optimal readability.                                        |
| **Primary Brand**  | Slate Slate     | `#1E293B` | Deep navy-slate for structural borders, buttons, and navigation elements.                              |
| **Accent**         | Electric Cobalt | `#2563EB` | Single focused accent color reserved exclusively for interactive links, hover states, and active tabs. |
